# Frog Merge — сервер и бот

Один файл `server.js`, Node 18+, без npm-зависимостей. Он:

- раздаёт игру (`../index.html`, стикеры, иконки) и подставляет в неё конфиг;
- проверяет подпись `initData` Telegram и ведёт состояние игроков в `data.json`;
- считает лидерборд, «общий пруд» недели и события (редкие лягушки, личные финалы);
- через `getUserGifts` определяет, какой Kissed Frog у игрока в профиле (режим холдера);
- создаёт счета в Telegram Stars (`createInvoiceLink`, валюта `XTR`) и выдаёт покупки после `successful_payment`;
- принимает карточки для шаринга, отдаёт их по публичному URL и готовит `PreparedInlineMessage` для кнопки «В чат»;
- раз в день пишет отчёт в чат холдеров и отвечает на `/play`, `/top`.

## Запуск

1. `@BotFather` → `/newbot` → токен. Затем `/newapp` для этого бота: короткое имя приложения и URL сервера.
   Ещё `/setmenubutton` можно не трогать, кнопка «Играть» приходит в `/start`.
2. Скопируй `.env.example` в `.env`, заполни `BOT_TOKEN`, `APP_URL` (публичный HTTPS), `BOT_USERNAME`, `APP_NAME`.
3. Добавь бота в чат Kissed Frog Holders, узнай ID чата (например, через `@getidsbot`) и впиши в `CHAT_ID`.
   Для дневного отчёта боту достаточно права писать сообщения.
4. `node server/server.js`. Для локального теста без токена сервер работает в dev-режиме: подписи не проверяются, платежи выключены.

HTTPS обязателен: Mini App, `shareToStory` и `photo_url` для карточек работают только с публичным адресом.
Проще всего поставить сервер за Caddy или nginx с сертификатом, либо на любой PaaS с Node.

## Что проверить в первый день

- `getUserGifts` на живом аккаунте: метод появился недавно, документация не описывает ограничения по приватности.
  Если для части людей он вернёт пусто, режим холдера получат не все. Запасной вариант: игрок присылает ссылку `t.me/nft/KissedFrog-N`.
- Тестовый платёж на 1★ («Покормить пруд»). После оплаты в `data.json` появится запись в `payments` с `telegram_payment_charge_id`.
  Возврат: `refundStarPayment` с этим id.

## Команды

- `/play`, `/start` — кнопка «Играть» (в личке `web_app`, в группе прямая ссылка `t.me/бот/приложение?startapp=chat`).
- `/top` — топ-10 и общий пруд.
- `/digest` — только для `ADMIN_ID`, отправить дневной отчёт вручную.

## Данные

`data.json` хранит игроков, покупки, пруд недели и события. Файл пишется атомарно с задержкой 1,5 с.
Карточки лежат в `cards/`, старше двух дней удаляются автоматически.
Для чата на несколько сотен человек этого достаточно; при росте переносится в Postgres без изменения API.
